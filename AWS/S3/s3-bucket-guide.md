# Creating an S3 Bucket

## 1. Open S3 Service

```text
Services → S3
```

---

## 2. Create Bucket

Click:

```text
Create Bucket
```

---

## 3. Enter Bucket Name

Rules:
- lowercase letters
- numbers
- periods
- hyphens

Example:

```text
ayush-demo-bucket
```

---

## 4. Create Bucket

Click:

```text
Create Bucket
```

---

## 5. Upload Files

Inside bucket:

```text
Upload → Add files → Upload
```

---

## 6. Delete Uploaded Objects

Before deleting bucket:
- select uploaded files
- click delete

---

## 7. Delete Bucket

Select bucket.

Click:

```text
Delete
```

Confirm deletion.

---

# S3 Use Cases

- File storage
- Image hosting
- Backups
- Dataset storage
- Static website hosting
